# Sincere Music Text

Update a file with the current artist and song name, playing in Apple Music, for OBS to display in a text field.

A command-line app that writes the current artist and song name, playing in Apple Music, for OBS to display in a text field. 

I use this on my stream, twitch.tv/DanielSincere

## Installation
There are a few ways to install this.

### Homebrew

```
brew install danielsincere/tap/sincere_music_text
```

### Download
You can download the pre-built binaries from the releases page on GitHub. https://github.com/DanielSincere/SincereMusicText/releases

## Run

```
SincereMusicText
```
